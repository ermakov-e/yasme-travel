# 0003 — Двойная тема: MUI + styled-components

- Статус: принято
- Дата: 2026-11-22

## Контекст

Проект одновременно использует MUI-компоненты и styled-components. В `src/app/styles/theme.ts` живут два независимых объекта: `muiTheme` и `styledTheme`. Без объяснения это выглядит как дублирование и провоцирует хардкод цветов.

## Решение

- `muiTheme` — для MUI-компонентов: палитра, типографика, `styleOverrides` кнопок и полей.
- `styledTheme` — для styled-components: `colors`, `spacing(8px × factor)`, `breakpoints`, `shadows`, `borderRadius`, `transitions`, `zIndex`.
- Оба дерева — из одной палитры (Emerald & Teal).
- Компоненты используют **только** значения из темы; hex, px и магические числа запрещены.
- `GlobalStyles` задаёт фон, скроллбар, focus-visible и selection.

## Последствия

- Нужно синхронизировать два дерева при изменении палитры.
- В MUI-компонентах допустимо `theme.palette`, в styled — `theme.colors`.
- Правило «никаких px» уже нарушено в нескольких местах; долг фиксируется в [platform/003](../specs/platform/003-fsd-cleanup.md).

## Альтернативы

- **Только MUI** — не покрывает сложные styled-композиции.
- **Только styled-components** — теряются готовые доступные компоненты MUI.
- **Один объект темы с адаптерами** — возможное улучшение, но требует рефакторинга всех компонентов.
