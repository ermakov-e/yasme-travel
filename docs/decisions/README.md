# Architecture Decision Records

ADR фиксируют значимые решения и их последствия. Формат: контекст → решение → последствия → альтернативы.

## Когда добавлять ADR

- Меняется архитектурная граница или правило слоёв.
- Появляется новая технология или библиотека.
- Принимается решение, которое будет неочевидно через полгода.
- Добавляется новое исключение из правил (например, новая прагма импорта).
