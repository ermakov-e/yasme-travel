# Definition of Done

Чек-лист готовности задачи. Пункты со звёздочкой (`*`) обязательны, если применимы к задаче.

## Спека

- [ ] Спека существует и имеет уникальный `id`.
- [ ] Статус `done`, поле `updated` обновлено.
- [ ] Все сценарии приёмки выполнены и отмечены.
- [ ] Изменения поведения отражены в требованиях, а не только в коде.
- [ ] `files` и `planned` соответствуют фактически затронутым файлам.
- [ ] `tests` заполнен, если тесты добавлены.

## Код

- [ ] Реализация соответствует спеке; отклонений нет или они согласованы.
- [ ] Не изменялись файлы вне `files` / `planned`.
- [ ] Соблюдены слои FSD; новых нарушений нет.
- [ ] Первичный файл помечен `// @spec <id>`.
- [ ] Нет `any` и неиспользуемого кода.
- [ ] Нет хардкода цветов, отступов, теней и z-index вне темы.
- [ ] Состояния loading / error / empty обработаны.
- [ ] Нет новых зависимостей без согласования.

## Проверки

- [ ] `npx tsc --noEmit` — без ошибок.
- [ ] `yarn lint` — без ошибок.
- [ ] `yarn docs` — выполнено.
- [ ] `yarn docs:check` — зелёный (или предупреждения осознанно приняты).
- [ ] Сценарии приёмки прогнаны вручную в `yarn dev`.
- [ ] Тесты добавлены, если настроен раннер и менялась логика.

## Документация

- [ ] `docs/generated/` обновлён генератором, не руками.
- [ ] `docs/generated/traceability.md` содержит спеку и её файлы.
- [ ] При изменении архитектуры добавлен или обновлён ADR.
- [ ] Публичные контракты отражены в `docs/api.md` или generated.
- [ ] Если появилась новая env-переменная — обновлён `.env.example`.

## Ревью

- [ ] Reviewer проверил диф против спеки.
- [ ] Blockers и majors закрыты.
- [ ] Нет регрессий в существующих сценариях.
- [ ] Коммит содержит код, спеку и generated вместе.

## Git

- [ ] Ветка названа по задаче (`feature/<area>-<slug>` или `bugfix/<slug>`).
- [ ] Сообщение коммита объясняет «что» и «почему».
- [ ] PR содержит ссылку на спеку и сценарии проверки.
