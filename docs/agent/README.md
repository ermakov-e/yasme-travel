# Агентский контур

Документы для агента, который реализует фичи в проекте. Цель — чтобы любая задача проходила одинаковый путь: **спека → план → код → проверки → документация → ревью**.

## Файлы

| Файл | Когда читать |
|---|---|
| [workflow.md](workflow.md) | перед любой задачей |
| [roles.md](roles.md) | при распределении ролей и передаче работы |
| [definition-of-done.md](definition-of-done.md) | перед коммитом и на ревью |
| [context-map.md](context-map.md) | чтобы понять, какие документы и модули затрагивает задача |

## Быстрый старт

1. Прочитайте `AGENTS.md` и этот файл.
2. Найдите спеку задачи в `docs/specs/` или создайте её: `yarn spec:new <area> "Название"`.
3. Определите слой и список файлов.
4. Реализуйте строго в рамках спеки.
5. Выполните `yarn docs`, `yarn docs:check`, `yarn lint`, `npx tsc --noEmit`.
6. Обновите статус спеки и закоммитьте код вместе со спекой и generated.

## Базовые запреты

- Не писать код без спеки.
- Не менять требования спеки во время реализации — сначала обновите спеку.
- Не выходить за список файлов без обновления спеки.
- Не редактировать `docs/generated/` вручную.
- Не нарушать зависимости слоёв FSD.
- Не использовать цвета, отступы и тени вне темы.
- Не добавлять зависимости без согласования.
