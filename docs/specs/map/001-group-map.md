# map-001 — Карта группы

## Контекст

Карта — ключевой экран продукта: группы отображаются точками. Сейчас `widgets/Map` — заглушка «Map will be here». Leaflet и react-leaflet уже установлены и используются в `LocationPicker` при создании группы.

## Требования

- Виджет `Map` отображает интерактивную карту.
- На карте отображаются группы в виде маркеров.
- Маркер содержит название группы и открывает детали по клику.
- Карта центрируется по локации текущей группы или по всем группам.
- Если координаты некорректны, карта не падает.
- На мобильном карта занимает доступную высоту экрана.

## Сценарии приёмки

1. Открыть `/groups/1` → карта центрирована на Эльбрусе, виден маркер группы.
2. Нажать на маркер → открывается карточка или модалка группы.
3. Открыть страницу с группой без `address` → карта работает по `lat` / `lng`.
4. Повернуть устройство / изменить размер окна → карта пересчитывает размер.

## Данные и контракты
