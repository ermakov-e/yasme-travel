# groups-003 — Детали группы

## Контекст

Маршрут `/groups/:id` существует, но страница показывает только заголовок и идентификатор. Списку нужен экран группы: название, обложка, участники, локация и переход к карте.

## Требования

- Страница `/groups/:id` загружает группу по `id`.
- Показываются название, обложка и список участников.
- Если группа не найдена — понятное сообщение и ссылка назад к списку.
- Состояния загрузки и ошибки обработаны.
- Несуществующий `id` не приводит к падению.

## Сценарии приёмки

1. Открыть `/groups/1` → отображается «Поход в горы», обложка и 3 участника.
2. Открыть `/groups/999` → сообщение «Группа не найдена» и ссылка на `/groups`.
3. Смоделировать ошибку сети → сообщение об ошибке и повтор запроса.
4. Во время загрузки виден индикатор.

## FSD

- `features/groups` — новый query `getGroup`.

## Данные и контракты

Планируемый контракт:

```ts
GET /groups/:id → Group            // 200
GET /groups/:id → { message }      // 404
```

Эндпоинт добавляется в `features/groups/apiSlice.ts`, мок — в `shared/mocks/handlers/groups.ts`.
