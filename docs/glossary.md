# Глоссарий

## Домен

| Термин | Значение |
|---|---|
| **Группа** (`Group`) | Объединение людей, привязанное к геолокации. Содержит название, обложку, локацию и участников. |
| **Локация** (`GroupLocation`) | Координаты `lat`, `lng` и опциональный `address`. Точка на карте. |
| **Участник** (`GroupMember`) | Человек в группе: `id` и `avatar`. |
| **Друг** (`Friend`) | Пользователь из мок-списка, которого можно добавить в группу. |
| **Фото** (`Photo`) | Изображение, привязанное к группе. В MVP — только тип, функциональность не реализована. |
| **Обложка** (`coverImage`) | URL изображения группы, показывается в карточке. |

## Архитектура

| Термин | Значение |
|---|---|
| **FSD** | Feature-Sliced Design — слои `app → pages → widgets → features → entities → shared`. |
| **Слой** | Уровень архитектуры с фиксированными правилами зависимостей. |
| **Слайс** (FSD) | Модуль внутри слоя (например, `features/groups`). |
| **Slice** (Redux) | Часть store, созданная через `createSlice`. Не путать со «слайсом FSD». |
| **RTK Query** | Слой работы с серверными данными на базе Redux Toolkit. |
| **Тег кеша** | Метка (`Group`, `User`, ...), связывающая query и mutation для инвалидации. |
| **Гвард** | Компонент-обёртка маршрута, проверяющий доступ (`AuthGuard`, `GuestGuard`). |
| **Модалка** | Диалог или bottom-sheet, управляемый через `modalSlice`. |
| **Прагма** | Осознанное исключение из правил (например, `@app/hooks`). |

## Документация

| Термин | Значение |
|---|---|
| **Спека** | Файл в `docs/specs/` с требованиями, сценариями приёмки и списком файлов. Единица задачи. |
| **Frontmatter** | Блок `--- ... ---` в начале спеки: `id`, `status`, `layer`, `files`, `planned`. |
| **Generated** | Страницы в `docs/generated/`, создаваемые скриптом из кода. |
| **ADR** | Architecture Decision Record — короткая запись о принятом архитектурном решении. |
| **`@spec <id>`** | Комментарий в коде, связывающий файл со спекой. |
| **Definition of Done** | Чек-лист готовности задачи. |
| **`docs:check`** | Гейт проверки документации: актуальность generated, валидность спек, ссылки, слои. |
